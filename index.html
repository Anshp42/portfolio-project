Project 1: Interactive Desktop Application - Deadly Desert Lab

Technical Stack: Python, Pygame, Object-Oriented Logic, Version Control

Problem Statement

Developing engaging, logic-driven simulation loops requires efficient collision detection, state management, and real-time asset rendering without introducing CPU processing bottlenecks.

Process & Reflection

I designed this system by separating rendering surfaces from the core simulation logic loops. A significant challenge was optimizing the asset calculation updates to prevent frame drops during complex interactions. By refactoring the update cycle to utilize delta-time rendering and tracking coordinates via structural vectors, I achieved stable, cross-platform performance execution.

Project 2: Algorithmic Matrix Engine - Tic-Tac-Toe Simulation

Technical Stack: Python, Multidimensional Arrays, Game Theory & State Verification

Problem Statement

Building local turn-based systems requires reliable grid evaluation state machines that can parse multi-directional coordinate matching paths efficiently without redundant memory consumption.

Process & Reflection

I structured this solution around multi-dimensional data structures representing coordinate layouts. The fundamental challenge was establishing clean conditional validation routes to sweep rows, columns, and diagonal trajectories after every input tick. I resolved this by utilizing deterministic loop structures to systematically scan matrix slices, reducing computational overhead and ensuring crisp, real-time index evaluation values.

Project 3: Object-Oriented Inventory Desktop Application

Technical Stack: Java, JavaFX UI Framework, Object-Oriented Programming (OOP)

Problem Statement

Small-scale logistics businesses need an intuitive, fast-loading visual application interface to update, track, and categorize warehouse asset stock metrics locally.

Process & Reflection

This system was built leveraging strong Object-Oriented principles, using custom model classes for stock components. Managing cross-window UI updates without introducing thread blocking proved difficult. By restructuring the software interface to separate the data logic from presentation classes, I successfully streamlined performance and eliminated interface freezing.
